# 发布状态更正

用户要求发布最佳可用版本，首次提交实际上传的是 `terrain-v3-retained30k-20261107` 历史源码、模型卡与截图，没有上传模型权重。将该历史基线作为所请求版本发布属于版本选择错误。本仓库当前只作为历史归档。

## 已核查的证据

- retained30k 模型卡明确记录两个配置都没有通过视觉验收，并有悬浮块、碎散植被、材质混杂和洞穴岩石不自然的问题。
- 后续主训练第 1500 步的固定局部对比中，若干样本的孤立块更多；不能仅根据训练步数推断质量提高。
- 后续 G0/BIO 第 100 步在两个地形配置的检查中仍有斑点与小空腔。原记录明确为 `best_model_changed=false`，没有接受新最佳版本。
- 后续第 250 步有局部指标改善，但现有局部比较不足以证明完整世界、所有配置、原生游戏和美观验收通过。
- 第 2250 步是已找到的后续主训练恢复断点。文件存在和可恢复训练都不能代替生成质量验收。
- 更早的二维高度场模型是另一条路线，其输出能力与当前三维洞穴模型不同，不能无说明地冒充三维模型升级版本。

以上是现有记录支持的判断，并非对所有未验证断点的质量结论。不能据此宣称已经找到了另一个完整且明显更好的可部署版本。

## 正确发布所需条件

先确认目标权重身份、完整阶段组合、匹配的词汇/归一化/导出模板和推理入口，再核验已有实际生成证据；如证据不足，应保持待验证状态。训练仍暂停，核查不会自动恢复付费 GPU 作业。

当前没有发布新的权重下载、量化结果、2 GB 内存实测或无缝无限世界支持。
